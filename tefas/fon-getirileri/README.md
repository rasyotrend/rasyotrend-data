# TEFAS Fon Getirileri

RasyoTrend tarafından yayımlanan TEFAS fon getirileri JSON verileri.

Bu klasörde aşağıdaki veri dosyaları yer alacaktır:

- menkul-kiymet-getirileri.json
- emeklilik-getirileri.json
- borsa-yatirim-fonlari-getirileri.json

Bu repo yalnızca kamuya açık veri çıktıları için kullanılır.
Veri üretim ve doğrulama kodları ayrı private repository içinde tutulur.
